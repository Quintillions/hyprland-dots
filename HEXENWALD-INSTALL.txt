WALPURGISNACHT: HEXENWALD - install notes
=========================================

HOW TO APPLY
  1. Copy this tree over your repo (same relative paths). Files here REPLACE your versions.
  2. Delete the obsolete files (list below) - ideally only after step 5 works.
  3. IM Fell fonts: put the .ttf/.otf files into assets/fonts/ (check their licence before you
     commit them). Optional: IM_FELL_Flowers_2 is decorative and not used by the current theme.
  4. Executable bits must be tracked by git or the scripts will not run:
       git add --chmod=+x config/hexenwald/bin/* config/rofi/scripts/*.sh config/hypr/scripts/*.sh
  5. Rebuild (your alias is nrsif):
       cd <repo> && git add -A && sudo nixos-rebuild switch --impure --flake .
     This also prunes the unused quickshell entry from flake.lock.
  6. Copy a wallpaper into ~/wallpapers (wallpapers/hexenwald-placeholder.png is an original,
     procedurally generated stand-in), then press SUPER+B or SUPER+C.

  SUPER+D  launcher (Rofi)         SUPER+V  clipboard           SUPER+C  wallpaper picker

PALETTE ADDITIONS (documented deviations from the nine colours)
  Rost #C4705A   urgent notifications, errors, failed unlock. A non-green signal colour was needed.
  ANSI colours   lighter tints of the palette (e.g. green #8AA37C) because Efeu itself is only 2.9:1
                 on Tiefwald and would be unreadable as terminal text.
  Efeu is used as a FILL with Mondlicht text (4.2:1), never as thin text on the dark background.

KNOWN RISKS / TROUBLESHOOTING
  * Workspace clicks: Waybar sends classic `dispatch workspace N`. Your Hyprland uses the new Lua
    config; if clicks do nothing, SUPER+1..5 still work. Test: hyprctl dispatch workspace 2
  * Eww windows: if SUPER+A does nothing run `eww logs` / `eww daemon --debug`. Syntax errors in
    eww.yuck show up there first. `eww open --toggle tabula` is the underlying command.
  * Brightness slider (LUMEN) needs DDC/CI and I2C access. Your config has no hardware.i2c.enable
    or i2c group. If `ddcutil detect` fails for your user the slider hides itself. Fix: add
    hardware.i2c.enable = true; and put quin in the i2c group.
  * No battery on a desktop: PILA rows hide automatically.
  * Rofi missing Wayland: if `rofi` in your nixpkgs is X11-only it still runs via Xwayland;
    otherwise replace `rofi` with `rofi-wayland` in modules/hexenwald.nix.
  * Fonts missing: the build warns if Iosevka Slab Nerd is absent; add the IM Fell files to
    assets/fonts/ or Waybar/Rofi fall back to a generic serif.
  * Moon phase is an approximation (mean synodic month, about +/- half a day).
  * Wallust accent could land outside the palette for some wallpapers; if it bothers you, delete the
    two accent templates from modules/wallust.nix and the @import line in waybar/style.css.
